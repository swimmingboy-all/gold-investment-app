# 🌟 Gold Matrix - 금 투자 지표 관찰 & 매수/매도 판단 웹앱

금 가격에 결정적 영향을 미치는 거시경제 및 수급 지표를 실시간/최근 통계 기반으로 관찰하고, 데이터 기반 가중치 모델을 통해 **"지금 금을 매수해야 하는가, 매도해야 하는가?"**를 진단해 주는 인터랙티브 대시보드 웹애플리케이션입니다.

---

## 🚀 GitHub Pages로 웹에서 바로 실행하기

이 웹앱은 별도의 백엔드 설치 없이 브라우저에서 직접 구동되는 정적 웹 애플리케이션(SPA)입니다. GitHub Pages를 통해 무료로 웹에 호스팅하여 PC, 태블릿, 모바일 어디서든 실행할 수 있습니다.

### GitHub Pages 활성화 방법:
1. 이 저장소를 본인의 GitHub 계정으로 푸시(Push)합니다.
2. 저장소 상단 메뉴의 **Settings** (설정)으로 이동합니다.
3. 좌측 사이드바에서 **Pages**를 클릭합니다.
4. **Build and deployment** 섹션에서:
   - **Source**: `Deploy from a branch` 선택
   - **Branch**: `main` 브랜치 및 `/ (root)` 폴더 선택 후 **Save** 클릭
5. 1~2분 후 상단에 생성되는 **`https://<사용자아이디>.github.io/<저장소이름>/`** 주소로 접속하면 즉시 웹앱이 실행됩니다!

| :--- | :--- | :--- | :---: |

| **5. 경기 & 고용** | 비농업 신규 고용(NFP), 실업률, ISM 제조업/서비스업 PMI, 장단기 금리차(10Y-2Y, 10Y-3M) | **경기 둔화 시 호재** (금리 인하 유도 및 안전자산 수요 촉진) | **10%** |
| **6. 위험 & 심리** | CBOE VIX(공포지수), 지정학 리스크 지수(GPR), 주식/채권 분산투자 상관관계 | **위험 고조 시 호재** (전쟁, 분쟁, 금융위기 시 최종 피난처) | **10%** |
| **7. 상대 가치** | 금/은 비율(Gold-Silver Ratio), 금/구리 비율, 금/S&P500 비율, M2 통화량 대비 금 가격 | 상대적 고평가/저평가 판단 척도 (금/은 80 이상 시 안전자산 선호 극대화) | 보조 |
| **8. 실전 팁 & 캘린더** | FOMC, CPI, 고용보고서 D-day 카운트다운 및 FRED, WGC, CFTC 공식 소스 | 변동성 대비 및 진입 시점 조율 | 캘린더 |

## 🎯 핵심 기능

1. **종합 매수/매도 시그널 계기판**:
   - -100점(적극 매도) ~ +100점(적극 매수) 게이지 미터기.
   - 핵심 상승 동력(Top Drivers) vs 리스크 요인 실시간 분석 요약.
   - 국내 투자자를 위한 원/달러 환율 연계 투자 전략(KRW 환산 효과) 및 권장 포트폴리오 비중 제시.
2. **가중치 모델 프리셋**:
   - `균형 추천형 (기본)` / `실질금리 집중형` / `수급 & 탈달러형` / `위험 & 침체 방어형`
3. **What-If 민감도 시뮬레이터**:
   - 10년 TIPS 실질금리, 달러인덱스(DXY), 환율, 중앙은행 매입량을 슬라이더로 조절하여 향후 시나리오별 매수/매도 판정 변화 즉시 시뮬레이션.
4. **인터랙티브 차트**:
   - 8대 축 강도 레이더 차트, 실질금리 vs 금 가격 듀얼 축 역상관 차트, DXY vs 환율, 중앙은행 매입 및 ETF 흐름, 장단기 금리차 추이.
5. **투자 메모 & 리포트 출력**:
   - 브라우저에 저장되는 개인 투자 결정 메모 및 원클릭 인쇄/PDF 보고서 출력 지원.

## 💻 로컬에서 바로 실행하기

- **방법 1 (가장 간단)**: `index.html` 파일을 크롬, 엣지 등의 브라우저로 더블클릭하여 바로 실행.
- **방법 2**: `run_app.bat` 더블클릭 실행.
- **방법 3**: PowerShell에서 `.\server.ps1` 실행 (`http://localhost:8088`).
